optik
=====

optik builds compact k-mer indexes and de Bruijn graphs from sequencing data, and maps reads against references.
A Rust command-line front end drives a C++ core through a C ABI, and a Python bench checks both against published tools.

This site covers all three layers and the Lean proofs of their algorithms.
The C++ pages are generated by Doxygen and rendered by Breathe, so every file's header comment opens its page with the data layout and flow it implements.
Python modules shared by the bench come from their docstrings, while the Rust API reference is rustdoc's own output.
The Lean proofs get a page built from their module headers and docstrings, with the theorem map from ``lean/APPENDIX_B.md``.

Building
--------

``docs/build.sh`` runs Doxygen, Sphinx and ``cargo doc`` in that order and writes the site to ``docs/_build/html``.
Doxygen's own HTML, with source browsing and call graphs, goes to ``docs/_build/doxygen/html``.
Graphviz and Doxygen come from the system, while the first run installs the pinned Sphinx side from ``docs/requirements.txt`` into ``docs/.venv``.
On Nix, one shell provides the system tools.

.. code-block:: bash

   nix-shell -p doxygen graphviz --run docs/build.sh
